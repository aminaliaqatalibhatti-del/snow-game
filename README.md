# ❄️ Snow Mountain — Diamond Hunter

A browser-based 3D snow mountain survival game built with Three.js.
No installation required — just open in any browser!

## 🕹️ How to Play

| Control | Action |
|---|---|
| **WASD / Arrow Keys** | Move |
| **Shift** | Sprint |
| **Space** | Jump |
| **Mouse** | Look around |
| **Click** | Lock mouse / focus |
| **ESC** | Pause |

---

## 🎯 Objective
- Collect **5 glowing blue diamonds** scattered across the snow mountains
- **Avoid sniper energy shots** fired from random mountain directions
- A **red laser warning** appears 1 second before each shot — dodge it!
- Collect all 5 diamonds to **WIN** 🏆

---

## ⚠️ Rules
- You have **100 HP** — each sniper hit deals **34 damage** (3 hits = Game Over)
- Diamonds spawn at **fixed locations** across the map
- Sniper fires every **2–5 seconds** from random directions
- Use **Sprint** to move faster (watch your stamina bar!)

## ✨ Features

| Feature | Details |
|---|---|
| 🏔️ **Snow Mountain Terrain** | Procedural Perlin noise — realistic peaks, valleys, frozen lake |
| 👩 **Female Explorer** | 3rd person character — winter jacket, hat, scarf, backpack |
| 💎 **Glowing Diamonds** | 5 collectibles with glow effects and particle lights |
| 🔴 **Sniper Warning** | Red laser beam 1 sec before shot |
| ❤️ **Health Bar** | Visual HP with color change |
| ⚡ **Sprint / Stamina** | Sprint bar depletes and recharges |
| ⏱️ **Timer** | Track your completion time |
| ⏸️ **Pause Menu** | ESC to pause anytime |
| 💀 **Game Over Screen** | Stats shown on death |
| 🏆 **Victory Screen** | Time shown on win |
| ❄️ **Falling Snow** | 6000 animated snow particles |
| 🌲 **Pine Trees** | Snow-covered trees on slopes |
| 🌙 **Night Sky** | Moon, stars, atmospheric fog |
